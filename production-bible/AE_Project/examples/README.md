# examples/

Configuration and usage examples (populated as the API stabilizes). Planned:

- `reskin_palette.jsx` — override `SR.config.palette` before `SR.build()` to generate an alternate colorway.
- `vertical_9x16.jsx` — set `SR.config.comp` format to build the 1080×1920 social variant.
- `calm_vs_lively.jsx` — drive `Master Drift Speed` / `Master Amplitude` to show the animation range.

Each example sets config overrides, then runs the build, demonstrating the one-knob art-direction model.
